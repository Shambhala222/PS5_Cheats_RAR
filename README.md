# PS5 etaHEN Cheats (RAR)

Same trainers as [PS5_Cheats](https://github.com/Shambhala222/PS5_Cheats), packed like Yami: one `.rar` per game in `mc4/`.

## How to use

1. Put the `.rar` in `/data/etaHEN/cheats/mc4` (FileZilla or PS5 explorer).
2. On the PS5: **Cheats (WIP) → Cache And Reload Cheats List**.
3. If etaHEN does not see the cheat, extract the `.rar` and put the `.mc4` in that same folder.

Raw `.mc4` files (CheatRunner / official etaHEN style): [Shambhala222/PS5_Cheats](https://github.com/Shambhala222/PS5_Cheats)
